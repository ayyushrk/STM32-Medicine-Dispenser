# 💊 IoT Smart Medicine Dispenser

An automated, intelligent pill-dispensing system designed to help patients—especially seniors or those with complex multi-medication routines—take their prescribed doses accurately and on time.

## ✨ Features
- **Real-Time Clock (RTC) Integration**: Keeps precise time to trigger precise alarm schedules.
- **Automated Dispensing**: Uses servo or stepper motors to mechanically release the correct compartment pill.
- **Audio-Visual Alerts**: Emits buzzer alarms and flashing LEDs to remind users when it's time for their medication.
- **Microcontroller Powered**: Built using ESP32/Arduino for reliable performance and optional Wi-Fi notification capabilities.
